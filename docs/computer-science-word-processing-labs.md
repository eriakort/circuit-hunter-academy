# Chapter 8 — Word Processing interactive labs

This increment adds practical, bilingual activities to the two existing Grade 9 Computer Science missions in Chapter 8.

## Mission mapping

- `c8m1` — The Scribe's Art: Word Processing (sections 8.1–8.2): document formatting, title preview, font and alignment controls, editable versus fixed-layout formats (.docx, .odt, .pdf, .txt), and a safe find-and-replace preview.
- `c8m2` — Images, Tables & Healthy Habits (sections 8.3–8.6): image/text wrapping choices, optional data table, hyperlinks and equation elements, plus an ergonomic workstation check.

## Learning and safety notes

- The formatting studio is an interactive model; it does not create or save a real document.
- Find-and-replace is a preview only. Learners are reminded to review matches before replacing all occurrences in a real editor.
- The sample planet table is illustrative.
- Ergonomics guidance uses a general 50–70 cm viewing-distance target and screen-at-eye-level reminder. It is not medical advice; learners should adjust for comfort and accessibility needs.
- Sharing reminders encourage descriptive links and avoiding disclosure of private information.
- All newly introduced labels, status messages and explanations are bilingual.

## Verification

Playwright coverage checks both mission routes in English and Italian, live formatting preview, document-format guidance, find-and-replace preview, layout controls, table visibility and ergonomic feedback.
