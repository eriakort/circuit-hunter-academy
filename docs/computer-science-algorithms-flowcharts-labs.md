# Chapter 11 — Algorithms and flowcharts interactive labs

This increment expands the existing Grade 9 Computer Science missions without adding duplicate curriculum entries.

## Mission mapping

- `c11m1` — Maps of Logic: Flowcharts: a labelled flowchart with terminal, input/output, process and decision symbols; guided step tracing; and a live even/odd input example.
- `c11m2` — Branch & Loop: a decision simulator with two selectable conditions and a bounded counter-controlled loop that learners can run and reset.

## Learning notes

- Reinforces sequence, selection and iteration, plus the purpose of common flowchart symbols.
- Explains how arrows define order and how a decision selects a branch.
- Loop count is bounded from 1 to 8 to keep the simulation predictable and safe.
- All new UI labels, explanations and feedback are bilingual (English/Italian).
- The simulations do not execute arbitrary code or modify files.

## Verification

Playwright covers both missions in English and Italian, flowchart tracing, parity output, branch selection and loop execution.
