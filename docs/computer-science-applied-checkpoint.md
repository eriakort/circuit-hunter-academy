# Applied Computer Science checkpoint

The first Computer Science checkpoint assesses foundational concepts in algorithms, binary data, hardware and networking. This follow-up checkpoint covers the remaining applied strands so the learner can demonstrate a broader Grade 9 skill set.

## Unlock requirements

All 20 Grade 9 Computer Science missions below must be cleared:

- Cybersecurity: `c6m1`, `c6m2`, `c6m3`
- Spreadsheets: `c9m1`, `c9m2`, `c9m3`
- Flowcharts and program logic: `c11m1`, `c11m2`, `c11m3`
- Python foundations and operators: `c12m1`, `c12m2`, `c12m3`
- Python selection and Boolean logic: `c13m1`, `c13m2`
- Python iteration: `c14m1`, `c14m2`
- Python strings, lists and files: `c15m1`, `c15m2`
- Python functions and project structures: `c16m1`, `c16m2`

## Four applied challenge arenas

| Arena | Assessment topics |
| --- | --- |
| Cyber Shield Arena | Strong unique passwords, phishing recognition, ransomware recovery and backups |
| Spreadsheet Strategy Grid | SUM, relative/absolute references and IF logic |
| Python Logic Lab | Data types, range/for loops and Boolean operators |
| Python Builder’s Trial | String slicing, LIFO stacks and function return values |

## Assessment and progression

- 12 bilingual questions across four themed arenas.
- A score of at least 10/12 is required to pass.
- A successful first completion awards 50 XP once only.
- Attempts, best score, last score and completion use the shared checkpoint progress model.
- The checkpoint is Grade 9 and Computer Science only; it does not alter the first foundations checkpoint.
