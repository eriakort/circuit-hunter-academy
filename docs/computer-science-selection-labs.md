# Chapter 13 — Selection and Boolean logic labs

This increment strengthens the existing Grade 9 Computer Science missions `c13m1` and `c13m2` with interactive, bilingual practice.

## Mission c13m1 — The Crossroads: if / elif / else
- A grade slider drives a three-branch decision.
- The selected branch is highlighted so learners can see that Python checks conditions from top to bottom and runs only the first matching branch.
- The code preview reinforces comparison operators, the difference between assignment (`=`) and equality (`==`), colons and indentation.
- English and Italian labels, branch names and explanations are provided.

## Mission c13m2 — Logic Gates & match…case
- Two Boolean inputs can be toggled independently.
- AND, OR and XOR operations calculate a deterministic 0/1 output.
- A day selector demonstrates `match…case`, including a grouped weekend case and the wildcard `case _`.
- English and Italian labels and feedback are provided.

All activities are deterministic client-side learning simulations. They do not execute arbitrary Python code.
