# Chapter 12 — Python variables and data types lab

This increment expands the existing Grade 9 Computer Science mission `c12m2` without adding duplicate curriculum entries.

## Learning goals
- Explain that `input()` returns text (`str`).
- Recognise the four introductory types: `str`, `int`, `float` and `bool`.
- Distinguish `str`, `int` and `float` conversion.
- Assign an input value to a named variable and use it in a simple calculation.
- Recognise valid variable identifiers and avoid Python keywords.
- Understand `print()`, assignment with `=`, and comments beginning with `#`.

## Interactive lab
- Learners edit a variable name and input text.
- A conversion selector demonstrates keeping text or converting with `int()` / `float()`.
- The code preview updates with the chosen conversion and optional comment.
- A deterministic simulator displays the next numeric value or a helpful conversion/name error.
- No arbitrary Python code is executed.

All new labels, explanations and feedback are bilingual (English/Italian).
